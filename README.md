## 📖 О проекте

**Green Club** — это многостраничный сайт спортивной академии гольфа с 7 страницами, тёмной темой, адаптивным дизайном и динамическими маршрутами для статей.

### 🎯 Цель проекта
Продемонстрировать навыки фронтенд-разработки: работу с компонентным подходом, TypeScript, роутингом, адаптивной вёрсткой и организацией кода в реальном проекте.

---

## 🛠 Технологии

### Основной стек
- **Vue 3** — реактивный фреймворк с Composition API и `<script setup>`
- **TypeScript** — строгая типизация для надёжности кода
- **Vite** — современный сборщик с мгновенным HMR
- **Vue Router 4** — клиентская маршрутизация с динамическими роутами
- **SCSS** — стили с переменными, миксинами и вложенностью

### Архитектурные решения
- **Data-driven подход** — контент статей хранится в отдельном файле `data/articles.ts`
- **Универсальный компонент** `ArticlePage.vue` — один компонент рендерит все 6 статей
- **CSS-переменные** для темизации — плавное переключение между светлой и тёмной темой
- **Feature-based структура** — компоненты группируются по назначению (layout, sections, ui)


### Ключевые решения

**1. Единый источник данных для статей**
Вместо 6 отдельных страниц — один массив данных и один универсальный компонент. Это позволяет:
- Легко добавлять новые статьи (просто добавить объект в массив)
- Избежать дублирования кода
- Автоматически генерировать навигацию между статьями

**2. Типизированный контент**
Использованы discriminated union types для разных типов секций статьи:
```typescript
type ArticleSection =
  | { type: 'heading'; text: string }
  | { type: 'paragraph'; text: string }
  | { type: 'image'; src: string; alt: string; caption?: string }
  | { type: 'list'; items: string[] }
  | { type: 'facts'; items: { title: string; text: string }[] }
```

**3. Темизация через CSS-переменные**
Тёмная тема реализована без JavaScript-логики в компонентах — достаточно переключить атрибут `data-theme` на `<html>`.

## 📄 Страницы сайта

| Страница | URL | Описание |
|----------|-----|----------|
| Главная | `/` | Hero-секция, преимущества, статистика, CTA |
| О гольфе | `/about-golf` | Список из 6 статей с карточками |
| Статья | `/about-golf/:slug` | Динамическая страница с контентом |
| Академия | `/academy` | Группы, модули обучения, расписание |
| Расписание | `/schedule` | Таблица занятий + карта локаций |
| Тренеры | `/coaches` | Карточки тренеров с био и достижениями |
| Контакты | `/contacts` | Форма обратной связи + FAQ |

## 🚀 Установка и запуск

### Требования
- Node.js 18+
- npm 9+

### Шаги установки

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/ТВОЙ_ЮЗЕРНЕЙМ/green-club.git
cd green-club

# 2. Установите зависимости
npm install

# 3. Запустите dev-сервер
npm run dev

# 4. Откройте в браузере
# https://helili1.github.io/Green_club/
```

### Сборка для продакшена
```bash
npm run build      # Сборка в папку dist/
npm run preview    # Предпросмотр собранной версии
```
